**Sistema de Autogestión Policial**

El Sistema de Autogestión Policial es una plataforma diseñada para gestionar trámites policiales de manera online, facilitando y agilizando el proceso tanto para los ciudadanos como para el personal policial.

**Descripción**

Este sistema permite a los usuarios realizar distintos tipos de trámites policiales sin necesidad de acudir físicamente a las oficinas. A través de una interfaz intuitiva, los ciudadanos pueden solicitar, gestionar y dar seguimiento a sus trámites de forma rápida y segura.

Por otro lado, el personal policial tiene la capacidad de validar, rechazar y gestionar solicitudes, asegurando un control eficiente y transparente del proceso.

**Funcionalidades Principales**

Gestión de trámites online: Solicitud, validación y seguimiento de trámites policiales.

Roles diferenciados: Usuarios ciudadanos, personal policial y administradores.

Pago en línea: Integración con medios de pago digitales para realizar pagos de trámites, en este caso Mercado Pago.

Generación de certificados: Documentos oficiales descargables directamente desde el sistema.

Validación de documentación: Escaneo y verificación de identidad por parte del personal policial.

**Tecnologías Utilizadas**

Frontend: React.js

Backend: Django

Integración de Pagos: API de Mercado Pago

Base de Datos: PostgreSQL
